# Shopee Afiliado

Painel pessoal para descoberta de produtos, análise de oportunidades e organização de materiais autorizados para afiliados Shopee Brasil.

## Segurança

- Nunca publique App ID, App Secret, tokens ou dados privados da conta.
- Credenciais serão fornecidas somente por variáveis de ambiente locais.
- Este repositório é independente de outros projetos.

## Integrações

O backend oficial de afiliados será incorporado com os créditos e a licença de seus autores. A integração real depende das permissões da conta Shopee.
